# I-know-tt

Notes and reference material for Tenstorrent (TT) development.

## Purpose

A shared knowledge base for the Tenstorrent stack — hardware architecture, the
`tt-metal` runtime, kernel programming, and debugging workflows — kept in a form
that can be reused across projects.

## Consumed as a submodule

This repository is mounted at `thirdparty/I-know-tt` by the `tt-loop-scheduler`
project. To populate it in a fresh checkout:

```bash
git submodule update --init thirdparty/I-know-tt
```
